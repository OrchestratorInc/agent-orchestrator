Orchestrator.inc (formerly Agent Orchestrator, AO) is a free, open-source (Apache-2.0) desktop app for orchestrating AI coding agents such as Claude Code and Codex on macOS, Windows, and Linux. A project orchestrator agent plans work and spawns workers. Each worker gets an isolated workspace, keeps its conversation or terminal available, and connects its Git work to pull requests, CI, reviews, and merge conflicts.

The agents write the code. Orchestrator helps you manage projects and sessions, follow work, send instructions, review changes, and open browser previews.

<Callout type="info" title="Fastest path">
	Download the desktop app, add a repository, and start one small session. See [Installation](/installation), then [Quickstart](/quickstart).
</Callout>

<span id="what-ao-helps-you-do" />
## What Orchestrator helps you do

- Plan larger outcomes with a project orchestrator agent that breaks work into tasks, spawns workers, and follows them.
- Close the pull-request loop: CI failures, review comments, and merge conflicts go back to the worker that owns the change.
- Run AO reviewer agents on a worker's pull request, using any reviewer-capable harness, and send requested changes back to the worker.
- Run several coding agents in parallel without mixing their files, branches, or pull requests, and follow them on a live Kanban board.
- Choose a native terminal UI or structured Chat for each session, and switch between them where the harness supports it.
- Let agents preview and drive a session's local app in an agent-controllable browser.
- Open the artifacts agents write, such as Markdown reports, SVGs, images, and HTML pages, with version history and restore.
- Schedule recurring work with Automations and reuse project instructions or shell commands with Cues.
- Follow and steer workers on several computers from the companion iPhone, iPad, or Android app through Connect Mobile.

Orchestrator works best when each worker has a clear, reviewable outcome: a focused bug, feature, refactor, test, documentation update, or review follow-up.

## The basic loop

```text
add project -> start session -> isolated worktree -> pull request -> CI/review -> merge -> cleanup
```

Create sessions from the desktop app or the optional CLI. Orchestrator starts the selected agent interface and combines saved activity and pull-request data to show a session's status.

## Chat and Terminal UI

Every session has one active agent interface at a time:

| Interface | Best for |
| --- | --- |
| **Chat** | Structured messages, activities, approvals, plans, usage, and conversation history. |
| **Terminal UI** | The agent harness's native interactive terminal experience. |

Chat support depends on the harness and installed version; see the [agent capability catalog](/plugins/agents#chat-versus-terminal-ui). Compatible sessions can switch interfaces without changing their session or worktree; the UI shows which transitions are available.

## Where local data lives

<span id="local-by-design" />

The desktop app runs a Go background service on `127.0.0.1` and talks to it through a local API. Orchestrator stores app data and worktree metadata under `~/.ao` by default. Most integrations use coding agents and source-control credentials already on your computer; Orchestrator does not bundle external agents or their credentials. Unreal Agent is a built-in Chat-only adapter on macOS and Linux.

Connect Mobile is a separate, opt-in listener protected by a connection password. See [Connect Mobile](/configuration/remote-access) for local and secure remote pairing.

This manual is checked against the latest stable release, [v0.13.3](https://github.com/Untrivial-ai/agent-orchestrator/releases/tag/v0.13.3), published 1 October 2026. Newer controls on `main` may differ from that release. Check the [changelog](/changelog) and its release notes before using a new control.

Orchestrator Cloud is available now in the desktop app (turn on **Settings → General → Developer mode**, then **Cloud**): sign in and run agents in hosted sandboxes. Local use stays free; see [Plans](/guides/cloud#plans). See the [Cloud guide](/guides/cloud) for setup.

## Supported agents

Orchestrator ships adapters for 37 coding agent harnesses, including Claude Code, Codex, Cursor, Gemini CLI, Aider, OpenCode, Droid, Kimi Code, and GitHub Copilot. Each project chooses its own worker, orchestrator, and reviewer agents. Support for Chat and reviewer roles varies by harness. Check the [agent catalog](/plugins/agents) for details. Cloud offers a smaller [provider set](/guides/cloud#get-started).

GitHub and GitLab provide source-control observation and issue intake. Intake is opt-in and read-only toward the issue tracker; Linear and legacy Node plugin packages are not supported.
