---
title: Hermes Agent
---

AO runs the official Nous Research Hermes Agent v0.21.6 classic interactive CLI on Linux. Install the pinned official release, configure a provider with native `hermes model`, and refresh Harness settings. AO never installs a global plugin or edits your native profile.

Standing instructions append through the native ephemeral system prompt, preserving the effective native profile/personality overlay. Tasks seed interactive chat once through a private query file. Default permissions preserve native approval decisions; explicit bypass uses native `--yolo`. Accept-edits, auto and AO tool allow/deny overrides are refused.

AO observes the current rendered composer and a read-only native process lease. Settlement can lag native idle by the normal 30-second observer interval. Restore requires the full observed native ID, persisted messages, the same workspace and no compressed successor; missing/title/latest targets fail closed. The private instructions are rebuilt for every launch. Native Ctrl+C cancels a turn; AO Kill terminates the supervised runtime.

Model IDs use free-form native `--model` input; AO has no verified model catalog. Credential presence reports configured or unknown, not verified authorization. Chat, cross-interface handoff, reviewer mode and agent switching are unavailable. Non-Linux lease observation is unsupported.
