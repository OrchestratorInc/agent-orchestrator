---
title: Hermes Agent
---

AO runs the official Nous Research Hermes Agent classic interactive CLI on macOS, Linux and Windows. Install it from **Settings → Harnesses**: on macOS and Linux AO prefers Homebrew's `hermes-agent` release bottle, and otherwise runs Hermes's official installer (`install.sh`, or `install.ps1` on Windows), which clones the GitHub repository, with its interactive setup skipped. Both install the latest release; updates use `brew upgrade` or native `hermes update`. AO accepts Hermes v0.21.6 and later at `/opt/homebrew/bin/hermes`, `/usr/local/bin/hermes`, `~/.local/bin/hermes`, `~/.hermes/hermes-agent/.hermes/bin/hermes`, `/usr/bin/hermes`, or `%LOCALAPPDATA%\hermes\bin\hermes.exe`. AO checks these locations directly rather than executing a `hermes` found earlier on `PATH`, and never installs a global plugin or edits your native profile.

Use **Set up Hermes Agent** to run native `hermes model` in AO's terminal: choose a provider, then paste an API key or finish its OAuth flow. AO's auth check runs native `hermes status` and reports the provider Hermes resolves, including credentials Hermes reuses from Claude Code or GitHub, as configured; with no provider, Hermes needs setup. Hermes has no command that verifies a credential, so AO never reports it as authorized. If the status check is inconclusive, an API key in AO's environment or `<HERMES_HOME>/.env`, or an OAuth credential in `auth.json`, counts as configured. `HERMES_HOME` defaults to `~/.hermes`, or `%LOCALAPPDATA%\hermes` on Windows.

The model list shows the default from Hermes's `config.yaml`; any other model ID can be typed directly and is passed as `--model`. Effort is passed as native `--reasoning` (`none` through `ultra`). The provider stays native configuration.

Standing instructions append through the native ephemeral system prompt, preserving the supported native personality/instruction overlay, and are rebuilt for every launch. Tasks seed interactive chat once through a private query file. Default, auto and accept-edits approval modes all keep native Hermes approval prompts, because Hermes has no matching tiers; explicit bypass uses native `--yolo`. AO tool allow/deny overrides are refused.

Each fresh launch starts a native conversation under a private AO title (`--continue <title> --create-if-missing`). Restore resumes that title without creating one, and Hermes follows it forward through context compression; a conversation renamed or deleted in Hermes fails restore instead of silently starting over. Native `/new` starts a separate conversation, and restore returns to the AO-titled one. Sticky and named profiles, managed configuration, and environment-expanded native instruction configuration are refused. Native Ctrl+C cancels a turn; AO Kill terminates the supervised runtime. Settlement can lag native idle by the normal 30-second observer interval.

Chat, cross-interface handoff, reviewer mode and agent switching are unavailable.
