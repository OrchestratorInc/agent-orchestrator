# 全局 worktree 保存路径设置

## 已确认决策

- 全局统一路径，已有 worktree 保留原位。
- 本文为实施计划，尚未实施或运行功能测试。

## 功能与交互

- 在“设置 → 通用 → 会话”新增“Worktree 保存路径”，提供路径输入、选择文件夹、保存、恢复默认。
- 展示当前生效路径，提示“仅影响之后创建的 worktree，已有目录保持原位”。
- 保存后立即生效，无需重启。取消文件夹选择不修改输入；保存失败保留输入并显示错误。
- 指定目录直接作为根目录，例如设置 `E:\AO-worktrees` 后，普通会话保存到 `E:\AO-worktrees\<项目ID>\<会话ID>`；保留现有主编排器目录命名规则。
- 设置针对本机所有 Git 项目，不新增项目覆盖；Scratch、云端工作区和数据库目录沿用原行为。

## 设置与持久化

- 复用现有守护进程 settings 服务及 SQLite 存储，不写入前端本地偏好。
- `GET /api/v1/settings` 增加 `worktreeRoot` 和 `defaultWorktreeRoot`；前者为空表示使用默认目录。
- 新增 `PATCH /api/v1/settings/worktree-root`，请求为 `{ "worktreeRoot": "绝对路径" }`；空字符串恢复默认，缺失字段或 `null` 返回参数错误。响应沿用完整设置快照。
- 默认目录仍为 `<AO_DATA_DIR>\worktrees`。新增迁移保存自定义路径，并登记历史使用过的根目录；路径切换与历史登记在同一事务内完成。
- 按仓库脚本创建迁移、登记迁移编号，修改 SQL 查询后运行 `sqlc`；同步生成 OpenAPI 和前端类型。
- 前端复用现有文件夹选择桥接、设置行和保存组件；补充中英文文案及搜索关键词。旧守护进程未返回新字段时隐藏入口。

## 创建、恢复与清理

- 守护进程提供统一的根目录解析与校验，创建、恢复、观察、删除和清理脚本使用同一套规则。
- 每次会话创建或预创建只读取一次路径快照，单仓库、多仓库及编排器创建均使用该快照，避免并发修改设置导致目录分散。
- 已有及已预创建的 worktree 继续使用持久化的实际路径；连续切换目录、恢复默认、重启守护进程后仍可恢复和清理。
- 历史根目录保留登记，不因设置变更失去管理资格。`.discarded` 使用 worktree 所属根目录，保持同盘移动，并在启动时处理已登记根目录中的遗留回收内容。
- 保留脏 worktree、Git 探测失败及清理失败时的现有保护行为，不迁移或强制删除已有目录。

## 路径校验与验证

- 自定义路径必须是绝对路径，支持中文及空格。保存时规范化并解析物理路径，拒绝文件、磁盘根目录及与已登记根目录嵌套冲突的路径。
- 新根目录须不存在或为空；已登记的 AO 根目录允许再次选择。不存在时创建目录，并通过临时文件验证可写性；失败不更新设置，不清空用户目录。
- 自定义目录后续不可用时明确报错，不静默回退默认位置；缺失的历史目录不导致其他根目录的会话无法启动。
- 使用真实临时 Git 仓库和 SQLite 验证：默认创建、切换路径、重启持久化、旧会话恢复与清理、多仓库一致性、预创建期间切换、恢复默认及非法路径拒绝。
- 前端验证选择、取消、保存、失败提示、恢复默认及旧版本兼容；运行相关 Go 测试、HTTP 契约检查、前端测试、类型检查和构建。
- 通过 `ao preview` 检查设置交互；原生文件夹选择在隔离数据的 Electron 环境验证，交付时列出实际命令与结果。
