# Accounts desktop evidence

Actual Linux Electron packages with the native preload, bundled daemon and real provider catalog, each in a separate credential-free home, PID and network namespace. Before is the preserved635efb9 package. After uses the exact tested frontend bytes in this commit; provenance.json contains their SHA256 values. No component fixtures, browser-only reconstruction or intercepted API responses are used.

The synthetic session account lives in the existing encrypted vault. The device descriptor is signed out and contains no credential file. The verification badge is seeded fixture metadata, not a provider-authentication result. Usage therefore shows its real unavailable state. No provider login, reset credit, session switch or deletion was submitted.

The recording shows keyboard provider filtering, focus restoration, setting a default through the real isolated daemon, disabled permanent removal with readable impact, recovery access and both legacy settings links landing on Accounts. It consists of timestamped captures of the actual Electron window, encoded without replacing screen content. All selected stills and representative recording frames were inspected for privacy and rendering.

Live subscription values, completed provider switching and the same-target no-op are supported by preserved component/API/race checks, not newly demonstrated by this offline desktop fixture. Prior same-target screenshots remain separately attributed under ../pr-5769-same-target. The five retirement acceptance gates remain open; the UI blocks new permanent-removal submissions.
