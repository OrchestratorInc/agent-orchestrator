## 读「版本历史」时的关键区分

| 说法 | 实际含义 |
|---|---|
| 「Windows 离线限定范围 PASS」 | **不**代表真实 Provider、Windows Hello 正向、安装升级通过 |
| 「开发检查点已提交」 | 代码已入库，**不代表**验收通过 |
| 「运行时实现完成」 | 打包与人工生命周期验收可能仍未完成 |
| nightly tag 存在 | 该构建被产出，不代表稳定发布 |

## 知识库过期检测

每个 L3 文档的 frontmatter 有 `last_updated` 与 `source_files`。交叉验证 `source_files` 的 git 修改时间与 `last_updated` 即可判断是否过期；超过 14 天建议增量刷新，超过 30 天且有重大变更建议重建。
