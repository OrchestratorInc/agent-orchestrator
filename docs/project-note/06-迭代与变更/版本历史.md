## 上游功能里程碑（`docs/STATUS.md` 的 Shipped 段）

已交付主线：

1. **单 Agent 本地闭环**：加项目 → spawn 会话/orchestrator → attach 终端 → 观察 PR → 合并。
2. **双模式控制器**：TUI（原生 PTY/ConPTY，tmux legacy/fallback）与 Chat（无运行时，driver 协议），含耐久 drain/interrupt 接口切换。
3. **分离式 Chat host**：Codex 与 ACP 会话由认证分离 host 拥有，桌面关闭/退出/更新换 daemon 时 detach + reconnect，不打断在途 turn。
4. **多 harness**：38 个 worker/TUI-Chat harness、24 个 Chat driver、22 个 reviewer adapter。
5. **持久 Chat 会话**：turn/message/activity/approval/input/usage/compaction/rollback、有界历史分页、controller generation 围栏。
6. **SCM 观测**：GitHub/GitLab，ETag 条件请求 + 语义 diff + nudge 回路。
7. **通知中心**：四类耐久通知 + 分页历史 + 实时流 + 已读确认。
8. **移动端**：Connect Mobile（opt-in 认证 LAN 监听器）、配对 v2、管理与 cloudflared/Tailscale 远程接入。
9. **浏览器自动化**：会话级 `WebContentsView` + 认证 CDP 桥 + 打包的 `agent-browser` 二进制。
10. **OpenAPI 从 Go DTO 生成**、前端类型生成与 CI 漂移门禁。

## 已知未完成（`docs/STATUS.md`「In flight」）

- **Cloud 可用性**：客户端与桌面集成存在，但受构建配置、账号权益、控制平面可达性三重门禁。
- **浏览器自动化验收**：运行时实现完成，Windows x64 打包通过；macOS/Linux 打包与人工生命周期验收仍待。
- **跨接口原始终端历史导入**：支持原生历史重放的 provider 可 TUI→Chat；resume-only agent **fail closed**；不重建 PTY 滚动历史。
- **在途工具可移植性**：drain 可完成、interrupt 可取消，但没有 provider 协议能序列化正在执行的工具调用或分离后台进程供另一控制器接管。
- **Tracker 镜像**：GitHub/GitLab intake 已接，需 `AO_TRACKER_INTAKE=on` + 项目 assignee 规则；对 issue 仍只读（不回写评论/状态）。
- **完整原始 PR/tracker 事实暴露**：CDC 事件暴露（issue #110）与 `ao session get`（issue #111）仍开放。
