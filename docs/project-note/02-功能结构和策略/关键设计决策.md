# 关键设计决策

记录**有 trade-off 的历史决策**，含被否方案。逐条对应 `docs/adr/` 或设计文档，冲突以 ADR 原文为准。

## D1 · 主监听器永远 loopback、无认证

- **决策**：`127.0.0.1:3001` 无认证；**刻意不提供** `AO_HOST`。
- **替代**：加 token / TLS / 可配置 host。
- **理由**：daemon 是本地 sidecar，桌面与 CLI 同机；认证带来的成本大于收益，而一个 `AO_HOST=0.0.0.0` 会立刻变成公开无认证服务。
- **代价**：任何本机进程都能操作 daemon。
- **落地**：`LoopbackHost` 为常量；如需非默认 loopback，必须带 `IsLoopback()` 校验而非裸读 env。

## D2 · 第二个 LAN 监听器（Connect Mobile）

- **决策**：仅在用户显式开启「Connect Mobile」时绑定 `0.0.0.0`，走 Bearer 密码中间件，只服务 app API，控制类路由仍 loopback 门禁。
- **替代**：隧道内嵌 daemon / 反向代理 daemon / 无认证 LAN。
- **理由**：手机需要真实可达端点，家庭网络可信时明文足够；认证边界清晰。
- **代价**：直连 LAN 明文；密码需轮换。
- **参考**：`docs/adr/0001-lan-listener-for-mobile.md`；当前托管 cloudflared / Tailscale TLS 只是**包裹**这条认证路径，不授权暴露主监听器。

## D3 · LAN 上唯一未认证路由 `GET /api/v1/identity`

- **决策**：仅此一条精确路径豁免 `authMiddleware`，返回不透明 host id 与移动契约版本。
- **替代**：允许手机盲连后报错 / 用密码探测。
- **理由**：私有 IP 不是身份，手机需要先确认「谁应答」再提交凭据；该路由不返回邮箱、Cloud 用户 ID 等敏感信息。
- **约束**：精确路径、仅 GET、在 lockout 检查之前；任何新增未认证路由都必须独立 ADR。
- **参考**：`docs/adr/0003-unauthenticated-identity-probe.md`。

## D4 · TUI + Chat 双模式，一会话一控制器

- **决策**：`sessions.mode` 持久单值；TUI 走 PTY 运行时，Chat 不建 agent 运行时；只有接口切换协调器能改 mode。
- **替代**：同时运行两种控制器；把 Chat 也塞进 tmux。
- **理由**：双活会重复消费 provider 会话、产生两份事实；写入竞争无法收敛。
- **代价**：切换有 drain/interrupt 语义与排队窗口，需 outbox。

## D5 · Codex / ACP Chat 使用分离的持久 host

- **决策**：每个 Chat 会话有自己的认证分离 host；桌面关闭、完全退出、更新换 daemon 时**detach + reconnect**，不重启 provider。
- **替代**：provider 进程作为 daemon 子进程。
- **理由**：daemon 重启不应打断正在进行的 turn；ACP 需保留已初始化快照、JSON-RPC 关联、待处理交互与已确认 prompt journal。
- **代价**：宿主生命周期、认证握手、孤儿回收复杂度上升；显式终止会话才销毁 host。
- **参考**：`docs/adr/0003-persistent-chat-provider-host.md`、`docs/research/persistent-acp-chat-hosts.md`。

## D6 · SQLite + 触发器 CDC，不引入消息中间件

- **决策**：SQLite WAL 单写多读；`change_log` 触发器 + 轮询 + 进程内 Broadcaster。
- **替代**：Redis/Kafka/NATS、应用层手写事件。
- **理由**：本地单守护进程，不需要分布式控制平面；触发器保证「写入成功 ⇒ 事件必达」。
- **代价**：扇出是全进程内同步；订阅者不得阻塞。

## D7 · sqlc 生成查询，gen/ 不手改

- **决策**：`queries/*.sql` + 迁移为源，`npm run sqlc` 生成 `storage/sqlite/gen/`。
- **替代**：GORM / 手写 ORM。
- **理由**：需要显式事务 SQL 与可预测的 CDC 写入；生成物与 schema 同步由 CI 漂移门禁保证。

## D8 · 迁移只增不改

- **决策**：已合并迁移永不修改；新增迁移 ID 为 UTC `YYYYMMDDHHMMSSsss`，并追加到 `shippedMigrations`。
- **理由**：用户已运行的库无法回退已应用的 SQL；改写会静默分裂 schema。

## D9 · CLI 是纯 HTTP 客户端（含手写 DTO 边界）

- **决策**：`internal/cli` 不打开 SQLite、不 spawn runtime、不调 adapter；DTO **手工镜像**而非从 OpenAPI 生成。
- **替代**：CLI 直接调用 service（旧 TS 实现的 in-process 行为）。
- **理由**：保证所有状态变化经过 daemon 的单一写路径；手写 DTO 让 CLI 可在 wire 层独立演进，并由 e2e 测试守住兼容性。
- **参考**：`docs/documentation-map.md`「CLI 的手写 DTO 是刻意的边界」。

## D10 · Git 用真实 `git` CLI，不用 go-git

- **决策**：`os/exec` 调系统的 `git`。
- **理由**：必须匹配用户真实仓库行为——凭据、hooks、LFS、submodules、user config。
- **代价**：依赖本机 git，错误需从 stderr 解析。

## D11 · 终端用 native PTY/ConPTY，tmux 降为 legacy/fallback

- **决策**：新会话用分离式原生 PTY host（macOS/Linux）与 ConPTY host（Windows）；tmux 只服务持久 legacy handle 与启动失败回落。
- **理由**：需要「当前屏模型」（styled viewport）来做人机安全判定（idle 表面 + 空 composer），tmux 只提供历史重放环。
- **代价**：平台分支多；`ao doctor` 仍在两平台探测 tmux。

## D12 · 不重建 PTY 滚动历史为消息

- **决策**：TUI→Chat 交接要求原生历史重放；**不**把任意终端字节解释成消息/工具卡。
- **替代**：从 PTY 输出「猜」出会话结构。
- **理由**：终端字节大量是重绘产物，不是规范 provider 事件；伪造历史会让用户误认上下文连续。
- **代价**：resume-only provider 的 TUI→Chat 交接**fail closed**。

## D13 · 展示状态派生而非存储

- **决策**：见 `设计模式与策略.md` 第 2 条。
- **替代**：写 `status` 列 + 后台更新。
- **理由**：PR 事实独立变化；写死的状态必然过期。

## D14 · 内部审查器（TUI reviewer）走能力网关 + 宿主信任

- **决策**：新增 provider 无关的 interactive-reviewer 能力网关与中立工作目录契约；现有 adapter 保持「实验性/宿主信任」，在补齐沙箱、环境替换、broker 前置条件前不宣称隔离。
- **理由**：原生模式与 prompt 不是 OS/网络隔离；不能把实验结果当安全保证。
- **参考**：`docs/adr/0002-secure-interactive-reviewer-gateway.md`。

## D15 · 多 Agent 工作流是既有 Session 之上的一层

- **决策**：`workflow*` 表与新 service 不绕过 daemon/API/SDK 边界；调度器只授予资格，副作用集中在 execution coordinator。
- **替代**：独立调度进程 / 独立队列服务 / 直接操作 worktree。
- **理由**：复用已验证的会话、worktree、审查与观测；保持单一耐久事实源（SQLite + CDC）。
- **代价**：需要严格的绑定状态机（含 unknown 态）与幂等键。
- **参考**：`docs/customization/design.md` §1「总体架构」「依赖与所有权」。

## D16 · 唤醒/保持唤醒（Awake）分作用域，互不撤销

- **决策**：Stay Awake 支持无限期、定时、到点、运行中应用、AO 浏览器下载等多种请求；关闭一个作用域不会撤回另一个。
- **状态**：实现中，物理验收待完成。
- **参考**：`docs/adr/0006-desktop-awake.md`、`docs/adr/0005-mobile-closed-lid-wake.md`（proposed）。
