# 编码规范

规则以 `AGENTS.md`（机器可读契约层）为权威；本文件是**面向改代码时的检查清单**。

## 改动粒度

- **外科手术式**：每个改动必须直接对应任务。禁止顺手清理、大范围重命名、格式化横跨、投机抽象、架构重构——除非任务明确要求。
- **一处修复一个 issue/PR**：需要独立工作就开新分支 + 新 PR。
- **干净切换**：换实现时迁移**所有**调用方，删除废弃代码/注释/别名/再导出，不留 shim。

## 分层与依赖（最常被违反）

| 规则 | 违反示例 |
|---|---|
| CLI 只通过 daemon HTTP + 共享 client helper | CLI 里 `sql.Open`、`exec.Command` 起 runtime、直接调 adapter |
| HTTP controller 只做编解码 + 校验 + 调用 service | controller 里写 SQL、开事务 |
| service 不持有外部系统句柄 | service 直接 `os.Exec` 调 git |
| adapter 只导入 `domain` + `ports` | adapter 导入 `service/*` 或 `httpd` |
| domain 保持纯净 | domain 引入 HTTP DTO 或外部 payload |

新增代码放哪：见 `docs/backend-code-structure.md`「Adding New Code」三节（新 HTTP 路由 / 新产品资源 / 新 adapter）。

## Go 约定

- `context.Context` 作为 I/O 或阻塞函数的**第一个参数**。
- 用法错误返回 `usageError`（退出码 2）；运行时/daemon 失败退出码 1。
- 错误信封与 requestId 必须原样透传给用户。
- 面向接口而非具体实现：一次性用例不要抽接口。
- 注释写**为什么**，不写「做什么」。仓库里大量注释解释非显然的约束，跟随该风格。

## lint 门禁（`backend/.golangci.yml`，golangci-lint v2.13.2）

`default: none`，显式启用 30+ linter，分四组：

| 组 | linter |
|---|---|
| 正确性 | `errcheck`（含类型断言）、`govet`（enable-all，禁用 `fieldalignment`/`shadow`）、`ineffassign`、`staticcheck`、`unused`、`errorlint`、`bodyclose`、`sqlclosecheck`、`rowserrcheck`、`nilerr`、`makezero`、`gocheckcompilerdirectives`、`reassign` |
| 死代码/样板 | `unparam`、`unconvert`、`wastedassign`、`copyloopvar`、`prealloc`、`dupl` |
| 风格 | `revive`（含 exported/error-strings/indent-error-flow 等 16 条 rule）、`gocritic`（diagnostic+performance+style）、`misspell`、`usestdlibvars`、`predeclared`、`nakedret`、`forbidigo` |
| 安全 | `gosec` |

- `max-issues-per-linter: 0`、`max-same-issues: 0`：**全量报告**，不屏蔽。
- `forbidigo` 的作用：daemon 内子进程必须走集中式隐藏进程路径（Windows 上不能弹出控制台）；例外要写 `//nolint:forbidigo // 原因`，如代码生成器。
- `revive: exported` 要求每个导出符号有文档注释。
- 格式化门禁：CI 跑 `gofmt -l`，非空即失败。

## 硬性禁止（来自 AGENTS.md）

1. 不存储派生的展示状态。
2. 不把失败/未知探针当作会话已死。
3. 不强制删除脏的注册 worktree。
4. 不修改已合并的 SQLite 迁移（新建迁移）。
5. 不手改 `storage/sqlite/gen/*`（改 queries/迁移 + `npm run sqlc`）。
6. 不从 store 方法手工发 CDC 事件（触发器是唯一来源）。
7. 不改主监听器绑定主机、不给它加认证。
8. 不新增除「opt-in LAN 监听器」以外的网络暴露；LAN 上只能有 `GET /api/v1/identity` 一条未认证路由。
9. 不把 AO 状态写到 `~/.ao` 以外（唯一写例外：Chrome native-messaging 指针文件）。
10. 测试不加网络调用（除非包已有集成模式）；用 `httptest`/fake/注入。

## Hooks 必须 gitignore（`hookutil`）

每个 adapter 写进工作区的 hook 文件必须被忽略，由 `hookutil.EnsureWorkspaceGitignore` 保证，sentinel 为：

```
# managed by agent-orchestrator: AO hook files stay out of git status
```

新增 adapter 的 `GetAgentHooks` 必须调用它；否则 hook 会出现在用户的 `git status` 里。

## 前端约定

- 服务端数据走 TanStack Query；本地 UI 状态走 Zustand；**不要**把 daemon 数据放进 Zustand。
- 一律经 `lib/api-client.ts`（类型安全 + 错误信封 + requestId）；不裸 `fetch`。
- IPC 只经 `window.ao`（preload 暴露的窄方法集）；每个 `on*` 订阅在卸载时取消。
- 全局弹层挂在 `routes/_shell.tsx` 的宿主里。
- 生成物永不手改（`api/schema.ts`、`routeTree.gen.ts`）。

## 日志与遥测

- 用 `log/slog` 结构化字段；不要字符串拼接。
- 500 的错误真实原因通过 `envelope.WithErrorCapture` 进日志/Sentry，线上信封恒为 `Internal server error`。
- 遥测默认全关（`AO_TELEMETRY_*` 默认 off）。
