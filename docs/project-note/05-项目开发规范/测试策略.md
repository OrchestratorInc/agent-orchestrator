# 测试策略

后端 1445 个 `_test.go`、前端 623 个 `*.test.ts(x)`、66 个 Playwright E2E 规格。

## 写测试的要求（AGENTS.md + 工程规范）

永久测试必须能捕获**消费者可见的合理 bug**：

- ✅ 行为、边界、不变量、状态转移、优先级、错误路径
- ❌ 接线/拷贝/转发/mock 回声/源码文本/偶然默认值/同义反复/仅「不抛异常」/仅「非空」/重复同路径行

其他规则：

- 遵循所在包的既有风格（表驱动测试在本仓非常普遍）。
- 确定性、隔离、可在全量套件中安全运行。
- 不为「能跑」而缩小断言范围。
- 已有测试若断言的是**措辞/实现细节/偶然行为** → 删除，**不要**重新钉住。
- 不为不确定边界之外的情形新增长期测试；用一次性脚本验证后删除。

### CI 的关键细节

- **`-count=1`**：Go 测试缓存会被复用（曾出现 158/170 包报 cached 未实际执行）。必须禁用，但编译仍可缓存。
- **重包单独分片**：`storage/sqlite`、`service/chat`、`session_manager`、`storage/sqlite/store` 从 `backend-core` 中排除，由专用 job 以 20m 超时跑 race。
- **shard 0 做非测试步骤**：gofmt/build/vet 只在 `shard == 0` 跑，避免重复。
- `skip_global_compinit: "1"`：shell 测试环境隔离。

## 测试环境隔离（踩过的坑）

| 问题 | 正确做法 |
|---|---|
| Windows 下只设 `HOME`/`TEMP` **不足以**隔离 `os.UserHomeDir()` | 测试子进程必须同时设 `USERPROFILE`、`HOME`、`AO_*`、`AppData`、`XDG` |
| 测试写入真实 `~/.claude.json` | 必须隔离并核对真实配置哈希/mtime；漂移即中止（exit 97） |
| Chrome native-messaging 注册表键 `HKCU\Software\Google\Chrome\NativeMessagingHosts\dev.ao.browser_bridge` | HOME/USERPROFILE 隔离**不能**隔离 HKCU；测试必须显式注入目录模式或内存 fake（`testInstaller`） |
| Node 24（ABI 137）与 Electron 44（ABI 149）原生模块 | Node 测试通过的 `.node` 不能当桌面产物；打包须由 Forge 按 Electron ABI 重建 |
| ConPTY 网格断言依赖系统语言 | 不要只匹配 `mode con` 的英文输出；用 Windows API 读真实行列 |

## 提交前本地门禁（按改动范围选）

```bash
# 只改后端
npm run lint                                   # = cd backend && go test ./... && golangci-lint
cd backend && go test -race ./...

# 只改前端
cd frontend && npm run typecheck && npm run test

# 改了 API DTO / queries
npm run api && npm run sqlc                    # 必须提交生成物

# 改了共享包
npm run shared:check                           # cloud:check + product-ui:check
```

PR 交付前要求：**跑完对应 CI 的全部验证任务**（含完整套件，不只聚焦测试），并在 PR 描述里说明无法本地运行的任务及在 CI 的验证结果。**本地通过不等于远程通过**。
